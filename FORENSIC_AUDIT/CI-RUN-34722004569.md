## Strong clue for the current investigation

However, the owner reports a newer on-device error approximately resembling `invalid relative system link target`. Because PR #122 also changes root-relative symlink extraction, auditors should investigate whether the CI packaging fix and the Android extraction/symlink fix are two separate defects or two symptoms of the same packaging design.
